# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text at that link is the binding version.

## Summary

- Be respectful, welcoming and patient. Assume good faith.
- Critique code and ideas, not people.
- No harassment, insults, sexualised language or imagery, trolling, or
  publishing others' private information.
- The standard applies in all project spaces: issues, pull requests,
  discussions and reviews, and when representing the project elsewhere.

## Enforcement

Report conduct concerns privately to the maintainer,
[@bakhod1r](https://github.com/bakhod1r), by opening a
[private security advisory](https://github.com/bakhod1r/readable/security/advisories/new)
marked "Code of Conduct", or, for non-sensitive matters, an issue. Reports are
handled confidentially. Enforcement follows the Contributor Covenant 2.1
guidelines: correction, warning, temporary ban, permanent ban.
